# Pension Control V8 — ניתוח דוח הר הביטוח

גרסה זו מבוססת על V6 ומוסיפה ניתוח אוטומטי של קובץ Excel שהופק מאתר "הר הביטוח".

## מה חדש
- העלאת XLSX/XLS/CSV במסך הנתונים.
- זיהוי אוטומטי של כותרות דוח הר הביטוח.
- המרת פרמיות חודשיות לשנתיות וחישוב ממוצע חודשי.
- איחוד שורות לפי מספר פוליסה כדי לא לספור כל כיסוי כפוליסה נפרדת.
- חלוקה לרכב ודירה / בריאות וסיעוד / חיים / אחר.
- זיהוי נקודות לבדיקה: מספר פוליסות רכב, פוליסות ותיקות, סיעוד, ביטוח חיים, כתבי שירות בעלות 0 ועוד.
- Dashboard ביטוחי ייעודי.
- הקובץ עצמו נקרא מקומית בדפדפן ואינו מועלה לשרת בגרסה זו.

## עדכון האתר הקיים
כדי לא למחוק את הגדרות Supabase שלך, החלף ב-GitHub רק את הקבצים הבאים:
- `index.html`
- `app.js`
- `styles.css`
- `service-worker.js`

אל תחליף את `config.js` הקיים שלך.

לאחר Commit, בצע Ctrl+Shift+R או פתח חלון Incognito בגלל cache של ה-PWA.
